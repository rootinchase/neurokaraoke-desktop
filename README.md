# Native desktop app for https://neurokaraoke.com/

## This app is currently nowhere near finished, you may want to check out the [neuro-karaoke-wrapper](https://github.com/AferilVT/neuro-karaoke-wrapper) project if you want a functional app!

## Features:
- Playlists (kinda)
- Song playback
- Song search (kinda)
- Shuffle, loop, and volume controls
- Themes
- ...and more coming soon!

## Upcoming Features:
- Opus audio playback when opus is available (via [magnum](https://lib.rs/crates/magnum))
- Full API instead of a mirror
- Aggressive audio caching and streaming directly from disk
- Authentication & Accounts
